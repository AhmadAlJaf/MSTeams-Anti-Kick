# MSTeams-Anti-Kick
*An AI-generated JavaScript file that automatically rejoins any browser-based Microsoft Teams meeting that you were kicked from.*
This script has been tested and proven to work with personal and professional accounts as of its publication.

## How to try this script
This script can easily be implemented by pasting it into the Console section of Inspect Element but the change would easily be lost upon refresh.

### Chrome guide:
 1. Press the following key combinations `Ctrl` + `Shift` + `J` for **Windows** and `Cmd (⌘)` + `Option (⌥)` + `J` for **MacOS**
 2. If step 1 didn't work, then press the 3 vertical dots located at the top right end of your screen, on the same row as the box that has the website name in it. Then scroll down, click More Tools, then Developer Tools, then Console.
 3. Visit [MSRejoin.js](https://github.com/AhmadAlJaf/MSTeams-Anti-Kick/blob/main/MSRejoin.js "MSRejoin.js") then copy and paste the code into the Console.
 4. Close the console tab and enjoy your meeting without disruptions.

## How to Implement this script
If you'd like a configuration that'd last longer than a single browser session, then you'll need to follow this step to ensure your script is automatically injected every time you open Microsoft Teams in your browser.

 1. Visit [TamperMonkey.net](https://www.tampermonkey.net/) and install the browser extension for your given browser.
 2. If the extension doesn't appear in Chrome besides the box that has the website name in it, then press on the puzzle piece icon, then the pin beside Tampermonkey.
 3. Click on the Tampermonkey extension, then click Dashboard.
 4. This will take you to a page where you would have to click the plus-in-a-box icon.
 5. Delete the template code shown inside the editor.
 6. Visit [MSRejoin.js](https://github.com/AhmadAlJaf/MSTeams-Anti-Kick/blob/main/MSRejoin.js "MSRejoin.js"), then copy and paste the code into the Editor.
 7. Click File in the top-left corner of the editor, followed by Save.
 4. You may now close the tabs and enjoy all of your Microsoft Teams meeting without disruptions as long as you use the browser.
